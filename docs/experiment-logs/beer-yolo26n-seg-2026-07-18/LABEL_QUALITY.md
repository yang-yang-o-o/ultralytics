# 标注质量：还能再提升吗？

> 背景：提质后原分辨率 + `retina_masks` 预测观感已明显改善。  
> 问题：当前 YOLO 多边形标注相对原始 `mask/*.png`，是否还有提升空间？  
> 统计日期：2026-07-18；标注参数：`approxPolyDP(epsilon=0.0005 * peri)`（`beer_seg_prepare.py`）。

---

## 1. 当前标注量化（全量 1500 张）

相对原始二值 mask 填充多边形后：

| 指标 | 数值 |
|------|------|
| mask IoU mean / median | **0.9925 / 0.9927** |
| mask IoU min / p5 / p1 | 0.9861 / 0.9877 / 0.9871 |
| 多边形点数 mean / median / range | 133.9 / 133 / 54–196 |
| 边界带重合（形态学 gradient 近似）mean | **~0.58**（远低于区域 IoU） |

最差几张 IoU 仍 ≥ 0.986（如 `1066`, `682`, `1085`）。

**结论先说：**

- **区域重合已经很高**（~0.993）：再抠多边形，对 mAP 类指标几乎没空间。  
- **边界层仍有可见误差**：折线逼近圆滑瓶身/细颈时，边界带重合只有 ~0.5x 量级 → **观感/ Boundary F1 仍可能受益于更密轮廓**。  
- 相对「换分辨率 / retina_masks / 更大模型」，标注加密的 **边际收益更小**，但成本很低，值得做一次对照。

---

## 2. epsilon 消融（同图对比）

对样例 `0` / `323` / `1493`（`CHAIN_APPROX_NONE` 轮廓上逼近）：

| epsilon | 点数量级 | mask IoU |
|---------|----------|----------|
| 0（原始轮廓） | ~1000–1130 | **1.000** |
| 0.0002 | ~300–360 | **≈1.000** |
| **0.0005（当前）** | ~130–155 | **≈0.9992–0.9993**（单图；全库均值因实现细节略低至 0.993） |
| 0.001（早期） | ~30–40 | ≈0.996–0.997 |

说明：

1. 从 `0.001 → 0.0005` 已经吃掉大部分逼近误差。  
2. 再降到 `0.0002` 或直接存稠密轮廓，区域 IoU 可逼近 1，但点数翻倍～近 10 倍。  
3. Ultralytics 多边形标签点数过多会增加 I/O 与增广开销；一般 **200–400 点/实例** 已足够精细。

---

## 3. “提升空间”分两层看

### 3.1 多边形相对现有 mask（格式转换损失）— **有一点，但不大**

可做且便宜：

| 动作 | 预期 | 建议 |
|------|------|------|
| `epsilon=0.0002` 或自适应（面积大→更密） | 边界更贴，IoU→1 | 值得 A/B 一训 |
| `cv2.CHAIN_APPROX_NONE` 再逼近 | 保留更多真实轮廓点 | 与上类似 |
| 上限封顶（如最多 300 点） | 防极端长轮廓 | 推荐 |
| 孔洞 / 多连通 | 当前只 `RETR_EXTERNAL` | beer 几乎无孔，收益低 |

**不建议：** 为再涨 0.00x mAP 去存 1000+ 点；收益主要在边界观感，且训练更重。

### 3.2 原始 mask 本身的标注上限 — **可能才是更大的天花板**

当前多边形是在 **已有二值 mask** 上拟合。若原始 mask 来自渲染/投影：

- 边缘可能已有阶梯锯齿、膨胀/腐蚀偏差、与 RGB 未像素级对齐；  
- 多边形再密也只能逼近 **这份 mask**，逼近不了“物理真值轮廓”。  

若目视发现 GT mask 本身糊、胀一圈、或缺角，应优先：

1. 抽查 RGB vs `mask/*.png` 叠图（尤其瓶口、瓶底、反光处）；  
2. 必要时用更准的渲染、形态学修边、或 SAM/人工修难例；  
3. 再用更密多边形导出。

**学习点：** 转换精度 ≠ 语义标注精度。IoU(poly, mask)=0.99 只说明转换忠实，不保证 mask 对原图完美。

---

## 4. 和本次实验现象的关系

- 原分辨率 + `retina_masks` 观感变好，主要来自 **推理分辨率与 mask 上采样方式**，不是标注突变。  
- 数据“太干净 / ep15 就饱和”：单类、高对比、内外分布接近 → **指标无法区分标注再细一点的收益**。  
- 要用标注加密是否有用，应看：**Boundary F1 / 难例边缘叠图**，而不是 val mAP。

---

## 5. 建议决策

| 优先级 | 事项 | 是否建议现在做 |
|--------|------|----------------|
| 高 | 抽查 20 张 RGB↔原 mask 对齐（瓶口/底/截断） | ✅ 先做，判断天花板在哪 |
| 中 | `epsilon=0.0002` + 点数 cap 重导出，小对照训 | 可选 |
| 低 | 为 mAP 继续磨多边形 | ❌ 不值得 |
| 高（数据侧） | 更难 val / 外域图 / 更强增广，验证是否过拟合“干净室内瓶” | ✅ 针对收敛过快 |

**一句话：** 相对现有 mask，多边形还有 **边界级** 的一点空间；相对真实物体轮廓，要先确认 **原始 mask 质量**。对当前 beer 任务，标注已不是主瓶颈，观感提升已主要由模型侧（imgsz / retina / s 模型）贡献。
